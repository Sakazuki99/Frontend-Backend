# Командный проект

Учебный одностраничный сайт команды с профилями участников, практическими заданиями и менеджером задач.

## Технологии

- HTML5
- CSS3
- JavaScript без фреймворков
- [DummyJSON](https://dummyjson.com/) для демонстрационных задач и профилей пользователей

## Структура

~~~text
.
├── index.html
├── resume.html
├── css/
│   └── style.css
└── js/
    ├── fake-api.js
    └── script.js
~~~

index.html содержит основное приложение. resume.html — отдельная страница резюме команды.

## Запуск

Сайт не требует установки npm-зависимостей. Запустите любой локальный статический сервер из корня проекта. Например, с Python:

~~~bash
python -m http.server 8000
~~~

Затем откройте <http://localhost:8000>. На Windows команда py -m http.server 8000 также подойдёт, если установлен Python Launcher.

Менеджер задач загружает данные из DummyJSON, поэтому для него требуется подключение к интернету.

## Данные менеджера задач

DummyJSON используется как демонстрационный API. Создание, изменение и удаление задач имитируются на клиенте и действуют только до перезагрузки страницы. Для постоянного хранения нужен backend с базой данных.

## Известные ограничения

- Задачи, созданные в интерфейсе, существуют только на клиенте: DummyJSON их не сохраняет, поэтому для них запросы к серверу не отправляются.
- Профили команды продублированы в `index.html` и `resume.html` — при правке обновляйте оба файла.
