## 🚀 Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/PROJECT_NAME.git
```

### 2. Переход в папку проекта

```bash
cd PROJECT_NAME
```

### 3. Установка зависимостей

```bash
npm install
```

### 4. Запуск проекта

```bash
npm run dev
```

После запуска приложение будет доступно по адресу, который будет указан в терминале.
